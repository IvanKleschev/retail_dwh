# Правила качества данных

Автоматические проверки, реализованные в `sql/04_quality_checks.sql`:

## 1. Дубликаты в фактах
- Проверка: `COUNT(*) > 1` по комбинации `order_id + order_item_id`.
- Действие: удаление дубликатов (или алерт).

## 2. Пропуски внешних ключей
- Проверка: `WHERE customer_sk IS NULL` в фактах.
- Действие: анализ причины, исправление загрузки.

## 3. Корректность SCD2 в dim_customer
- **Перекрытия периодов:** поиск пар записей с `effective_from < b.effective_to AND effective_to > b.effective_from`.
- **Пропуски между периодами:** проверка через `LEAD`, что `effective_to` предыдущей записи равно `effective_from` следующей.
- **Дубликаты по дате начала:** `COUNT(*) > 1` по `customer_id, effective_from`.

Все проверки должны возвращать 0 строк.
